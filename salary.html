如何取得自己的 Google OAuth Client ID？（點擊展開）

1. 前往 Google Cloud Console → 建立專案 → 啟用 Google Calendar API、Google Sheets API、Google Drive API。
2. 在「OAuth 同意畫面」設定為外部並加入您的 Gmail 為測試使用者。
3. 在「憑證」建立「OAuth 用戶端 ID（網頁應用程式）」，於「已授權的 JavaScript 來源」填入您的 GitHub Pages 網址（如 https://bloodtw.github.io）。
