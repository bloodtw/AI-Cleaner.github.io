# ✨ AI 清潔排班神器 (AI Clean Scheduler)

📸 上傳清潔預約訂單或對話截圖，由 Gemini AI 自動辨識填表並一鍵建立 Google 日曆排班行程！

## 🚀 主要特色
- **智慧平台識別**：
  - 自動辨識「大管家平台」（工單明細截圖，自動排除金額干擾）。
  - 自動辨識「幫棒平台 / BounBang」（自動提取總收入並標註在備註最前方）。
- **服務項目智能簡化**：
  - 自動消除重複詞彙（如「幫棒居家-小套房清潔」簡化為「小套房清潔」）。
- **動態模型適配**：
  - 支援動態檢測 Google 官方最新、最優惠的視覺辨識模型（如 `gemini-3.1-flash-lite`）。
- **純前端運作，安全無虞**：
  - 無需任何後端伺服器，API Key 僅保存在使用者的瀏覽器本機端（LocalStorage）。
- **一鍵建立日曆行程**：
  - 自動整理標題：`【平台】區域 | 清潔類型 | 客戶姓名 | 電話`，並將地址與留言完整帶入日曆說明。
- **支援 GitHub Pages 免費部署**：
  - 支援手機（iOS / Android）及電腦跨平台使用，加入手機主畫面即可像 App 般快速開啟。

## 🌐 快速線上啟用 (GitHub Pages)
1. 在 GitHub 儲存庫頁面，點選 **Settings**。
2. 在左側導覽列找到 **Pages**。
3. 在 **Build and deployment** 下方的 **Branch** 選擇 `main` 分支，資料夾選擇 `/ (root)`，點擊 **Save**。
4. 等待 1~2 分鐘，即可透過網址 `https://<你的GitHub帳號>.github.io/<儲存庫名稱>/` 開始使用！
